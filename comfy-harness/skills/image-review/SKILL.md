# 出图评审 · 惊喜捕获第一

**评审第一问不是"主命题成立否"，而是"主命题之外有没有发现"。**

副产物知识（意外增益/意外减损/无法解释的异常）是全库最贵的经验——它花真实算力才换来、
无法从提示词反推（是条件交互效应）、且可跨场景复合复用。
**任何出图批次：评审先扫四类观察，再看主命题。** 20261008 实证：干净链手修的副产品
"倒影转正"差点蒸发在聊天流里，靠维护者人工追问才入飞轮——此教训即本 skill 诞生原因。

## 四类观察动词条（评审扫描顺序，逐类过）

| 类 | 定义 | 动作 |
|---|---|---|
| 增益 | 意外正向（例：干净链修复把倒影鬼影重绘成镜像小人） | 当场命名 + 落 obs 账本 + 够格即铸技巧草稿 |
| 减损 | 意外负向（例：风格 LoRA 的 blur DNA 糊手） | 隔离病因（同种子换单因子 A/B 是标准手法）+ 落 obs + 修法入判例 |
| 异常 | 无法解释的怪象 | 落 obs 标"未解"，不许静默放过 |
| 复现线索 | 触发条件（模型×构图×参数的交互） | 附着到对应增益/减损条目 |

## 捕获通道（一行即可——科目存在比写得漂亮重要）

- 批次伴生账本：`field/out/<prefix>_obs.jsonl`，每行
  `{"类":"增益|减损|异常|复现线索","现象":"…","条件":"…","证据":"文件名"}`；无观察写 `{"类":"无"}`。
- 够格项（有对照、可复算）→ **机械化铸判**：`py -X utf8 gov/obs_to_draft.py`
  （扫全部 `*_obs.jsonl`，够格者自动铸草稿并把 minted 写回账本；开关 OBS_FEED/--off/--dry-run）。
- **图证不入库**（20261008 维护者令）：`*.png/*.webp/*.jpg` 已由 .gitignore 挡出——
  证据=路径+sha256，原件留本地 `field/out/`；对外发布走 build_publish 通道（从文件系统复制，与 git 无关）。
- 不对称原则：**误记成本=一行，漏记成本=重跑发现它的算力——默认全记，人闸再删。**

## 闸双面 · 非放大 · 向量投影（20261008 工单载）

- **闸双面**：未批准不服务、也不影响——draft 不入挖掘基质（挖掘只读生成面+观察面+approved/verified）；
- **非放大**：合并不升信任级（draft 合并仍 draft；复现计数只进人决策面）；
- **向量投影**：嵌入缓存可全量重建、模型钉版（nomic v1.5/768）、语义层只服务 approved+verified。

## 评审其余检查（捕获之后才轮到）

1. 主命题验证：隔离变量（同种子换单因子）为标准手法，结论必须配对照；
2. 病灶专项：手部、细密纹理（铁丝网/网纹）、文字——历史病灶逐个点名检查；
3. 交付：成图+裁片落 `field/out/`（git 外，见上图证政策）；批次结论记 outcome 轴（咬合/不咬合/登记盲区三态诚实）。
